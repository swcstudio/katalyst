# Package Comparison

Compare Katalyst packages to help choose the right one for your needs.

## State Management

| Package | Use Case | Features |
|---------|----------|----------|
| @katalyst/hooks | Simple state | useState, useReducer patterns |
| @katalyst/core | Global state | Zustand stores |
| @katalyst/api | Server state | tRPC + React Query |

## UI Components

| Package | Focus | Best For |
|---------|-------|----------|
| @katalyst/core | Base components | General use |
| @katalyst/design-system | Design system | Themed apps |
| @katalyst/integrations | Third-party | Specific needs |

## Build Tools

| Package | Tool | Speed | Use Case |
|---------|------|-------|----------|
| @katalyst/build-system | RSpack | ⚡⚡⚡ | Modern builds |
| @katalyst/build-system | Webpack | ⚡⚡ | Traditional |
| @katalyst/build-system | Vite | ⚡⚡⚡ | Development |

# Frequently Asked Questions

## General Questions

### What is Katalyst?

Katalyst is a comprehensive full-stack framework combining React 19, RSpack, Deno, and multiple other technologies into a unified development system.

### Which packages should I use?

Start with:
- `@katalyst/core` - Core functionality
- `@katalyst/design-system` - UI components
- `@katalyst/hooks` - React hooks
- `@katalyst/api` - Backend APIs

### Are packages standalone?

Most packages depend on `@katalyst/core`. They're designed to work together but can be used selectively.

## Technical Questions

### What's the difference between @katalyst/core and @katalyst/hooks?

- `@katalyst/core`: Components, stores, utilities
- `@katalyst/hooks`: Unified hooks interface (100+ hooks)

### Can I use packages outside Katalyst?

Yes! Most packages can be used in any React 19 project.

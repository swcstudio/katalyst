# Building Custom Packages

Learn how to create your own packages in the Katalyst monorepo.

## Package Structure

```
packages/my-package/
├── src/
│   └── index.ts
├── package.json
└── tsconfig.json
```

## Creating a Package

1. Create package directory
2. Add package.json
3. Implement your code
4. Add to workspace

## Publishing

Packages can be published to npm or kept private within the monorepo.
